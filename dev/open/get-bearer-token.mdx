---
title: 获取 API 密钥
---
<Note>本指南适用于在营销助手平台生成的 API 密钥。若您的 API 产品使用了公私密钥加密，请参考[加密型开放端接入指导](/dev/open/connection)。</Note>

## 提前准备

在本教程开始前，你需要准备一个已注册好的账号。若无账号，可点击页面右上方的“[开始使用][]”进行注册。

## 简单四步走

登录账号，点击左下角的“API 密钥”，然后点击“创建 API 密钥”。
![网站主界面，点击左下角的“API 密钥”](/images/api-key-gen%20(1).webp)
![点击“创建 API 密钥”](/images/api-key-gen%20(2).webp)
为 API 密钥命名。
![为 API 密钥命名](/images/api-key-gen%20(3).webp)
密钥已为您生成，你可以点击密钥旁的“眼睛”来查看密钥信息。
![显示 API 密钥](/images/api-key-gen%20(4).webp)

## 接下来

当您拥有了密钥，您可以前往“[API 参考](/openapi-ref/)”栏目测试并体验 API。
